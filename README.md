# Lazarillo — Agente de Accesibilidad Digital

Agente de accesibilidad para personas con baja visión. No solo describe — ACTÚA: paga servicios, lee emails, navega sitios web, OCR documentos.

Demostrado en hackathon Dev Racing (pago CFE + receta médica).

## Stack
- Vite + React 18 + TypeScript + Tailwind CSS

## Build

```bash
npm install
npm run build
```

## Skill
El agente funciona como skill de OpenClaw. Ver `skills/lazarillo/SKILL.md` para instrucciones de uso.
